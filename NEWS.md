# norMmix 1.0-0

## New Features

* The `manyMLE` function is now officially exported. It no longer
  saves results to disk by default. The save functionality is retained
  in the `saveMLE` function.
* Exported string vector `norModels`, which lists all models in order.

## Bug Fixes

* Unused argument `trafo` was removed from `manyMLE` function.
